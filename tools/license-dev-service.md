# 本地账号与买断授权开发框架

本工具只用于公司电脑上的本地开发测试，没有真实付款、邮件发送或公网部署；发行端代码和私钥均不进入EXE。客户端配置仅接受 `http://127.0.0.1:端口`，原生客户端不会自动启动服务。

## 启动开发发行端

在项目目录执行，运行数据留库外 `build/licensing-dev`：

```powershell
python -B -X utf8 tools/license-dev-service.py --data-dir D:/Ai-Files/Repos/GitHub/sfx-tools/build/licensing-dev --port 48761
```

该命令会持续运行，Ctrl+C结束。首次启动生成RSA2048密钥；私钥仅以当前Windows用户DPAPI加密形式保存在 `issuer-private.dpapi`，公钥为 `issuer-public.blob`。重开服务复用同一身份，不覆盖异常或不匹配的密钥。无需管理员权限，不修改系统服务或防火墙。

## 客户端开发流程

1. 在软件“账号与买断授权”展开开发配置，填 `http://127.0.0.1:48761`，公钥路径填 `D:/Ai-Files/Repos/GitHub/sfx-tools/build/licensing-dev/issuer-public.blob`。这是手动选择开发信任来源，不接受凭证自带公钥。
2. 注册一个测试邮箱和至少12字符密码，再登录。账号/设备标识仅在本地；客户端不保存密码，登录会话只保留本次运行内存。
3. 打开设备与订单，创建测试订单，模拟支付，激活本机。服务最多允许两台有效激活设备，解绑后可重新激活。
4. 激活时，客户端使用固定公钥验证CNG RSA/SHA256签名，验证设备和发行信息后保存离线开发凭证；发行私钥不发送给客户端。
5. 模拟退款或解绑本机后清除本机有效凭证。其他离线设备无法即时知道服务器撤销，下一次成功联网核验后同步，符合已确定的永久离线买断边界。
6. 关闭服务/断网后仍可验证已有离线签名；关闭客户端后需重新登录开发账号，但离线凭证保留。任何授权异常均不阻止已有素材的读取与导出。

## 数据与安全边界

服务端SQLite只保存随机盐PBKDF2-SHA256密码摘要（400000轮）与会话令牌SHA256，不保存明文密码或会话。HTTP只绑定IPv4回环，拒绝浏览器Origin、非JSON和超64KiB请求，响应有长度限制与连接超时。客户端每次检查受信公钥指纹，凭证不能改写信任根。

开发服务的模拟支付接口不是正式支付回调；生产销售主体/渠道、服务部署、邮箱验证/密码找回、防爆破审计、真实回调验签、硬件绑定/防时钟回滚和商业许可合规均尚未完成。开发公钥可由本地用户更换，因此当前不作为可发布的防破解授权产品。基础软件功能尚未接付费锁定。

不要把运行目录、私钥文件、测试密码或会话写进知识库、源码或安装包。私钥与公钥不能随意重建；丢失发行端身份后，原凭证不能由新公钥验证。现有测试只证明本地合成工作流，不替代上线审计。

## 自动验证

```powershell
python -m unittest discover -s tests -p license_dev_service_test.py -v
```

Rust `licensing::tests` 另外覆盖公钥边界、基础功能始终可用、Python CNG与Rust验证互操作，以及临时回环服务的注册/登录/模拟支付/激活/解绑/退款闭环。测试只使用临时目录与本地随机端口，不接触真实用户账户或订单。
